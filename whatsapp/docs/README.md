# whatsapp docs

The human-facing half of the Dynasty WhatsApp door.
[`owner-onboarding.md`](owner-onboarding.md) is the one page an owner gets
at the invite, in English and Portuguese.
[`meta-setup.md`](meta-setup.md) is Afik's page for the Meta side: the
business account, the number, the token, the webhook and the one template,
each step marked done, waiting or his.
The mayor reads the skill [`../skills/whatsapp/SKILL.md`](../skills/whatsapp/SKILL.md)
before any WhatsApp reply, and a session bound to WhatsApp composes the
prompt fragment [`../template-fragments/whatsapp-v0.template.md`](../template-fragments/whatsapp-v0.template.md).
The design of record is
[`docs/design/whatsapp-adapter-20261103.md`](../../docs/design/whatsapp-adapter-20261103.md).
